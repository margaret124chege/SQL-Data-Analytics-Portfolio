## Project 1: AdventureWorks Sales & Product Analysis

### Project Overview

This project analyzes Microsoft's AdventureWorks sales and product data
using SQL Server and SQL Server Management Studio (SSMS).

The objective was to analyze product performance, sales volume, revenue,
and sales trends to answer common business questions.

### Business Questions

1. Which products are priced above $1,000?
2. Which products have no recorded sales?
3. Which products have the highest sales volume?
4. Which products generate the most revenue?
5. How does revenue change from month to month?
6. Which month generated the highest revenue?
7. Which year generated the highest revenue?
8. Which product category generated the most revenue?

### SQL Skills Demonstrated

- SELECT

- INNER JOIN
- LEFT JOIN
- Multi-table JOINs
- GROUP BY
- SUM()
- TOP
- CAST()
- NULL handling
- YEAR() and MONTH()
- Aggregate analysis

### Key Findings

- AWC Logo Cap had the highest sales volume with 8,311 units sold.
- Mountain-200 Black, 38 generated the highest product revenue.
- March 2014 generated the highest monthly revenue at approximately $7.22 million.
- 2013 generated the highest annual revenue.
- Bikes generated the highest revenue among product categories.
- The highest-volume product was not the highest-revenue product,
  demonstrating the difference between sales volume and revenue.
